## GCP-Neuro Notas 1.7.2 ✉️

### E-mail que explica o que fazer
- 🔑 Se o **Gmail** pedir **senha de app** (erro 534 / 5.7.9), o app mostra o passo a passo e um botão direto para criar a senha no Google.
- 🧭 Mensagens claras também para login recusado, SMTP bloqueado na Microsoft, falha de conexão, erro de TLS e remetente não autorizado — com "Tentar de novo".
- ✂️ Os espaços da senha de app ("abcd efgh ijkl mnop") são removidos automaticamente.
